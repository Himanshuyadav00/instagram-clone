# InstaClone 📸

A responsive Instagram-style social media UI built for learning and portfolio purposes.

## Features
- Instagram-inspired feed and stories
- Like interactions
- Create-post modal
- Profile and suggestions sidebar
- Responsive mobile navigation
- Explore-style visual layout
- Unsplash demo images

## Tech
HTML • CSS • JavaScript

## Run locally
Open `index.html` in a browser or serve the project with a local static server.

> This project is an independent educational replica and is not affiliated with Instagram or Meta.
